# GPT Batch Search

简体中文 | [English](README.en.md)

GPT Batch Search 是一个 Chrome 扩展插件，用于将大量条目逐条地发送给 ChatGPT，并将回答内容整理成 Markdown 文件、按目录结构保存到本地。支持树状目录解析、失败重试、对话导出和快捷消息等功能。

## 安装方式

1. 打开 Chrome 的扩展管理页面。
2. 开启「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 下载并解压本项目，加载解压出来的文件夹。

## 使用方式

批量任务通常按下面流程使用：

1. 在左侧填写全局 Prompt 和消息 Prompt。
2. 在右侧粘贴待处理条目或树状目录。正文名前需要以 ◆ 符号标记。没有 ◆ 的标题会被识别为 md 标题，标题会成为子文件夹的名字。最多可以使用三个等级的 md 标题。例子：

```
├─ 1. 古典诗学时期（Classical Poetics）
│  ├─ 1_1 Debates, Paradigm Shifts, and Contexts（论战、范式更新与时代背景）
│  │  ├─ ◆ 1_1_1 Plato on Poetry in Republic Book X（柏拉图《理想国》第十卷中的诗歌问题）
```

3. 选择任务模式（「新建对话」或「当前窗口」）。
4. 选择保存目录。
5. 点击「开始」运行批量任务。

任务运行时，页面下方会显示当前进度、成功数量、跳过数量、失败数量和日志。

## 主要功能

### 批量任务

- 粘贴多条标题或树状目录，按顺序逐条提交给 ChatGPT。
- 选择本地目录后，按任务树结构保存 Markdown 文件到对应子文件夹。
- 运行前自动识别已保存的标题，跳过重复条目。
- 每 30 条自动新建一个 ChatGPT 对话，降低长对话卡顿风险。

### 失败重试

- 保存失败、回答为空、ChatGPT 页面临时错误等情况会自动刷新重试。
- 默认最多刷新重试 5 次；前 2 次刷新当前页面，之后会在新标签页中继续。
- 不可重试的错误（目录权限、路径不存在等）会直接跳过，不会浪费重试次数。
- 任务结束后，失败条目会以树状格式列在底部，可以直接复制粘贴到待处理文本区域重跑。

### 回答整理

- 保存时会将 Markdown 链接、脚注、行内引用统一转换为末尾编号引用（endnotes）格式。
- 加粗和斜体 Markdown 标记会转换为 HTML 标签（`<strong>` / `<em>`），方便 Obsidian 等工具阅读。
- 自动过滤 ChatGPT 的 Sources 面板、思考过程标记、搜索工具调用残留等非正文内容。

### 保持网页焦点

- 批量任务依赖网页计时器和页面更新。窗口长时间失去焦点时，浏览器可能降低页面运行频率。
- 开启「保持网页焦点」后，任务心跳约 5 分钟没有更新时会刷新 ChatGPT 网页恢复任务；刷新后约 2 分钟仍没有推进时才会激活窗口。两次激活之间至少间隔 10 分钟。默认关闭。

### 对话导出

- 自动读取当前 ChatGPT 对话页面的所有问答，逐条保存为 Markdown 文件。
- 导出时会自动去除全局 Prompt 和消息 Prompt 前缀，只保留实际标题。
- 支持 Deep Research 结果的 DOM 解析与 Markdown 转换。
- 自动生成一份词条清单索引文件。

### 快捷消息

- 在任意网页选中文本后，按快捷键将选中文本拼接到预设 Prompt，发送到 ChatGPT。
- 支持 4 组独立预设，每组可分别设置 Prompt、是否自动发送、是否新建对话。
- 默认快捷键：Alt+Shift+W、Ctrl+Shift+1、Ctrl+Shift+2、Ctrl+Shift+3。

### 清理进度对话

- 批量任务运行期间会在 ChatGPT 对话标题中写入进度（如「CPTSD 4/70」）。
- 提供一键清理功能，扫描最近 3 页的 ChatGPT 对话，列出并删除标题包含进度格式的对话。

## 其他说明

- 设置页面支持中文和英文界面切换，切换时会同步替换默认 Prompt。
- 设置页面支持日间/夜间模式切换。
- 提供「学科地图 Prompt」一键复制按钮，方便生成知识结构大纲。
- 每条文本之间的等待时间可自定义（0 ~ 60 秒）。
- 忽略标题选项支持跳过一级标题和二级标题。
- 批量任务配置（Prompt、待处理文本、设置项）会自动保存，刷新或重启后恢复。

## 兼容性

- 适用于 Chrome 和 Edge 浏览器（Manifest V3）。
- 支持 chatgpt.com 和 chat.openai.com 域名。
