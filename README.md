# GPT Quick Search

GPT Quick Search 是一个 Chrome 扩展，用于快捷发送 Prompt、批量提交条目、保存 ChatGPT 回答，并将内容整理成 Markdown 文件。当前版本适合长期批量整理学科地图、人物词条、关键文本和主题说明。

## 主要功能

- 快捷消息：在选中文本后，使用预设 Prompt 发送到 ChatGPT。
- 批量任务：粘贴多条标题或树状目录，按顺序提交给 ChatGPT。
- 目录保存：选择本地目录后，按任务树结构保存 Markdown 文件。
- 已存在跳过：运行前会识别已保存标题，避免重复提交。
- 分段新建对话：批量任务每 30 条新建一个 ChatGPT 对话，降低长对话卡顿风险。
- 失败重试：保存失败、回答为空、临时错误等情况会刷新重试；多次失败后可尝试新标签页续跑。
- 回答整理：保存时会整理 Markdown 链接、加粗、斜体和末尾参考链接。
- 对话导出：可读取当前 ChatGPT 对话，并按问答保存到 Markdown。

## 安装方式

1. 打开 Chrome 的扩展管理页面。
2. 开启「开发者模式」。
3. 选择「加载已解压的扩展程序」。
4. 选择项目文件夹：`E:\gpt quick search v1\gpt-quick-search v1.0`

## 使用方式

打开扩展选项页后，可以配置全局 Prompt、消息 Prompt、任务模式、标题忽略规则、等待秒数和保存目录。

批量任务通常按下面流程使用：

1. 在左侧填写全局 Prompt 和消息 Prompt。
2. 在右侧粘贴待处理条目或树状目录。
3. 选择任务模式，例如「新建对话」。
4. 选择保存目录。
5. 点击「开始」运行批量任务。

任务运行时，页面下方会显示当前进度、成功数量、跳过数量、失败数量和日志。

## 保存格式

每个回答会保存为一个 Markdown 文件。文件名来自当前条目标题。

保存时会进行这些整理：

- `**加粗**` 会转换为 `<strong>加粗</strong>`。
- `*斜体*` 和 `_斜体_` 会转换为 `<em>斜体</em>`。
- 正文中的链接会转为数字引用，例如 `[1]`、`[2]`。
- 参考链接会统一放在末尾：

```md
## Footnotes

参考链接

[1] https://example.com
[2] https://example.org
```

当前版本使用末尾 Footnotes，不使用 Obsidian 块跳转。

## 运行提示

- 批量任务运行期间，ChatGPT 页面需要保持可访问状态。
- 如果 ChatGPT 页面结构变化，输入框、发送按钮或回答提取可能需要调整。
- 如果回答仍在生成，扩展会等待内容稳定后再保存，降低漏保存脚注的概率。
- 保存目录需要保持浏览器授予的读写权限。
- 大批量任务建议使用较短的等待间隔，并保持网络稳定。

## 关键文件

- `manifest.json`：扩展声明、权限和入口。
- `background.js`：后台任务、保存文件、批量状态和重试调度。
- `chatgpt_content.js`：ChatGPT 页面交互、发送消息、读取回答和批量执行。
- `options.html`：扩展选项页界面。
- `options.js`：选项页逻辑、任务树解析和状态展示。
- `theme.js`：选项页主题切换。

## 发布检查

发布前建议检查：

- 扩展能在 Chrome 扩展管理页正常加载。
- 快捷发送功能可用。
- 批量任务能提交全局 Prompt 和条目。
- Markdown 能保存到所选目录。
- 已存在文件会跳过。
- 失败重试和新标签页续跑日志能正常显示。
- 保存后的 Markdown 保留末尾 Footnotes。

## 未来可能的修改方向

- 增加「卡住时聚焦 ChatGPT 窗口」开关，仅在输入框长时间不可用时激活窗口。
- 增加「卡住时最大化 Chrome」选项，适合后台页面延迟渲染的情况。
- 增加断点续跑界面，可手动选择从某一条继续。
- 增加失败任务单独重跑功能。
- 增加保存格式预设，例如纯 Markdown、HTML 加粗、数字 Footnotes 等。
- 增加日志导出功能，便于排查长批量任务的问题。
- 增加任务队列管理，支持多个批量任务排队运行。
- 增加页面结构检测提示，在 ChatGPT 页面改版后提示需要维护选择器。
