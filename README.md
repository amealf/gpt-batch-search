# GPT Quick Search

简体中文 | [English](README.en.md)

GPT Quick Search 是一个 Chrome 扩展，用于批量提交条目，并将内容整理成 Markdown 文件、保存到本地。

## 主要功能

- 快捷消息：在选中文本后，使用预设 Prompt 发送到 ChatGPT。
- 批量任务：粘贴多条标题或树状目录，按顺序提交给 ChatGPT。
- 目录保存：选择本地目录后，按任务树结构保存 Markdown 文件。
- 已存在跳过：运行前会识别已保存标题，避免重复提交。
- 分段新建对话：批量任务每 30 条新建一个 ChatGPT 对话，降低长对话卡顿风险。
- 失败重试：保存失败、回答为空、临时错误等情况会刷新重试；多次失败后可尝试新标签页续跑。
- 回答整理：保存时会整理 Markdown 链接、加粗、斜体和末尾参考链接。
- 对话导出：自动读取当前 ChatGPT 对话，并按问答保存到 Markdown。

## 安装方式

1. 打开 Chrome 的扩展管理页面。
2. 开启「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 下载并解压本项目，加载解压出来的文件夹

## 使用方式

批量任务通常按下面流程使用：

1. 在左侧填写全局 Prompt 和消息 Prompt。
2. 在右侧粘贴待处理条目或树状目录。
3. 选择任务模式，例如「新建对话」。
4. 选择保存目录。
5. 点击「开始」运行批量任务。

任务运行时，页面下方会显示当前进度、成功数量、跳过数量、失败数量和日志。

## 保存格式

每个回答会保存为一个 Markdown 文件。文件名来自当前条目标题。

保存时会进行这些整理：

- `**加粗**` 会转换为 `<strong>加粗</strong>`。
- `*斜体*` 和 `_斜体_` 会转换为 `<em>斜体</em>`。
- 正文中的链接会转为数字引用，例如 `[1]`、`[2]`。
- 参考链接会统一放在末尾：

```md
## Footnotes

参考链接

[1] https://example.com
[2] https://example.org
```
